# JavaScript Classes – Mini Showcase

This project is part of the **JavaScript - The Complete Guide 2025 (Beginner + Advanced)** collection.  
It introduces JavaScript classes through a static item showcase, demonstrating how to create reusable blueprints for objects.

## 📌 Features
- Use of JavaScript `class` syntax to create item templates
- Static showcase that renders multiple items using class instances
- Clean structure separating data logic and presentation
- Simple and visually organized layout

## 🛠️ Tech Stack
- **Languages**: HTML, CSS, JavaScript (ES6+)
- **Styling**: Basic CSS
- **Tools**: VS Code, Git, GitHub

## 🚀 Live Demo
[Demo](https://flavia3107.github.io/javascript-oop-classes/)

## 📚 Learning Goals
- Understand JavaScript classes and constructors
- Create and manage multiple object instances
- Separate logic from data rendering
- Practice encapsulation and data modeling with classes
